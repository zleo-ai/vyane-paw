# VP-01: QwenPaw ↔ rmcp 3.0 compatibility

## Goal

Prove that an unmodified pinned QwenPaw MCP client can use the pinned
`vyane-rs` stdio server.

## Scope

- Pin exact QwenPaw and vyane-rs revisions.
- Launch and shut down the stdio server cleanly.
- Complete initialization and tool discovery.
- Execute one safe tool call and one deterministic error case.
- Produce a sanitized evidence record.

## Acceptance

- Automated test exits successfully on the supported development platform.
- Expected tool names are asserted, not only counted.
- Failure output contains no credentials, user paths, or private identifiers.
- Reproduction steps work from a clean checkout.
- An independent reviewer checks the evidence and compatibility claim.

## Non-goals

- Remote transport.
- MCP Tasks.
- Permanent gateway.
