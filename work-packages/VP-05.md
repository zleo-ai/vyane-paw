# VP-05: Final productization

## Goal

Package the integration and select one durable MCP 2026-07-28 capability for the
final demonstration.

## Acceptance

- Supported install, upgrade, rollback, and diagnostics are documented.
- Compatibility tests run in CI.
- The selected Tasks or MRTR capability has a bounded user story and evidence.
- Remote gateway work remains deferred unless its architecture decision is
  accepted.
